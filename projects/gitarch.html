gitarch

January–April 2026

A tool for analyzing git history. I wrote it completely by hand in Rust.

Running it on ripgrep

This was my first real coding project. I had just finished the Rust Book, the official guide to the language, and immediately fell in love with it. Rust was challenging to learn but very enjoyable, especially the functional programming aspects, which really messed with my object-oriented experience (some C++ in Unreal Engine doing game development, and Java from teaching myself the AP CSA course). A CLI tool was a good scope for a first project, and I was inspired by other CLI tools that had been rewritten in Rust, like ripgrep and fd (replacements for grep and find). The premise of gitarch is basically pure functions reading git history, so it leaned heavily on iterators and other functional features, and overall I felt Rust allowed for some very elegant solutions. All of the code is handwritten, and I finished it in a few months. It is far from a perfect project and not very technically difficult. I did have plans for async and multithreading, but I moved on to other projects before implementing them.
